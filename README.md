# Виртуальный стол

Пульт мастера для настольной игры. Карта игроков открывается на отдельном экране. Инструменты, заметки и кости остаются на мониторе мастера.

Сайт: [https://gregimuri.github.io/virtual_table_for_DND/](https://gregimuri.github.io/virtual_table_for_DND/)

Карты, рисунки и объекты хранятся только в этом браузере и никуда не отправляются.

## Как открыть стол

1. Откройте сайт в Chrome или Edge на компьютере мастера.
2. Загрузите карту или добавьте пустую сетку.
3. Нажмите «Экран стола» и выберите монитор игроков.
4. На этом мониторе щёлкните один раз, чтобы развернуть картину на весь экран.
5. Когда карта готова, нажмите «Показать игрокам» или дважды щёлкните её в списке «Карты».

Пока кнопка не нажата, игроки карту не видят: её можно править заранее. Стрелки листают карты только на пульте.

Если браузер не показывает список мониторов, откройте окно стола и перетащите его на нужный дисплей. Оба окна должны оставаться открытыми в одном браузере.

На экране стола видна только текущая показанная карта: рисунок, туман, сетка и объекты. Кнопок там нет.

## Пульт

- «Инструменты» — перемещение, кисть, ластик, туман и открытие тумана. Толщина запоминается отдельно у каждого инструмента.
- «Сетка» — клетки или гекс поверх карты. Её можно сдвинуть, перетащив карту с зажатым Alt.
- «Объекты» — картинки на текущей карте и библиотека с папками. Один файл из библиотеки можно поставить на любую карту сколько угодно раз. Цвет фона снимается пипеткой: правка в папке действует на копии, которые ещё не настраивали отдельно.
- Заметки и кости видны только мастеру.
- Проекты сохраняют карты, рисунок, объекты и библиотеку. Файл `.dndtable.json` можно перенести на другой компьютер.

Масштаб колёсиком и перетаскивание правой кнопкой меняют только пульт. Стол всегда показывает карту целиком.
