# Виртуальный стол

Пульт мастера для настольной игры. Карта показывается на отдельном экране игрового стола, как слайд. Инструменты остаются на мониторе мастера.

Сайт: [https://gregimuri.github.io/virtual_table_for_DND/](https://gregimuri.github.io/virtual_table_for_DND/)

Карты и рисунки хранятся только в этом браузере и никуда не отправляются.

## Как открыть стол

1. Откройте сайт в Chrome или Edge на компьютере мастера.
2. Загрузите карту или добавьте сетку.
3. Нажмите «Экран стола» и выберите монитор игрового стола.
4. На этом мониторе щёлкните один раз, чтобы развернуть картину на весь экран.

Если браузер не показывает список мониторов, откройте окно стола и перетащите его на нужный дисплей. Оба окна должны оставаться открытыми в одном браузере.

На экране стола видна только карта: рисунок, туман войны и расставленные фигуры. Кнопок там нет.

## Инструменты мастера

- Карты переключаются стрелками, как презентация.
- Кисть и ластик рисуют поверх карты. «Удалить весь рисунок» снимает все штрихи.
- «Туман» закрашивает область, «Стереть туман» открывает её. Можно залить карту туманом целиком.
- На пульте туман полупрозрачный, чтобы мастер видел карту. На столе он плотный. Режим «Скрыт» убирает туман только с пульта.
- «Добавить изображение» кладёт картинку поверх карты. Прозрачный PNG остаётся без фона. Для светлого фона включите «Убрать светлый фон».
- Фигуру можно двигать, менять размер и поворачивать. Экран стола повторяет положение.

Масштаб колёсиком и перетаскивание правой кнопкой меняют только пульт. Стол всегда показывает карту целиком.
